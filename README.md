# Modern CSS 2026 by Practice

## Практическое руководство по современному CSS

> От пустой папки — до полноценной Design System на чистом CSS 2026.  
> Практическое продолжение теоретической книги [Modern CSS 2026](https://github.com/rustkas/Modern-CSS-2026).

---

## О чём эта книга

**Modern CSS 2026 by Practice** — это практическое руководство, в котором читатель шаг за шагом создаёт один законченный проект и на нём осваивает все ключевые возможности современного CSS.

В результате прохождения книги у вас будет:

- рабочее приложение-дашборд **Nova**
- переиспользуемая **Design System**
- Style Guide
- документация, правила архитектуры и процессы поддержки
- реальные навыки работы с CSS 2026 без Sass и Bootstrap

Это не набор разрозненных примеров.  
Это один связный проект, который растёт от главы к главе.

---

## Для кого эта книга

- Frontend-разработчиков
- Тех, кто хочет перейти от «знаю свойства» к «умею проектировать CSS-архитектуру»
- Разработчиков дизайн-систем
- Тех, кто работает с React / Vue / Svelte / Angular и хочет лучше понимать CSS-платформу
- Всех, кто изучает современный CSS и хочет закрепить теорию практикой

## Что вы построите

### Проект Nova

В ходе книги создаётся:

1. **Nova Dashboard** — современное приложение
2. **Nova Design System** — переиспользуемое CSS-ядро
3. **Style Guide** — живая документация компонентов
4. **Документация и процессы** — architecture, tokens, contribution, governance, metrics, onboarding

### Используемые возможности CSS 2026

| Возможность | Применение в проекте |
|---|---|
| Cascade Layers (`@layer`) | Архитектура всей системы |
| Design Tokens | Единый источник стилей |
| OKLCH + `color-mix()` | Цветовая система и темы |
| CSS Nesting | Организация компонентов |
| `:has()` | Состояния форм |
| CSS Grid + Flexbox | Layout приложения |
| Container Queries | Адаптивность компонентов |
| Anchor Positioning | Tooltip, Dropdown |
| Popover API | Modal |
| View Transitions | Переключение тем |
| Scroll-driven Animations | Reveal-эффекты и progress bar |
| Logical Properties | RTL-готовность |
| `contain` / `content-visibility` | Производительность |
| Fluid Typography (`clamp`) | Адаптивная типографика |

## Принципы книги

1. **Один проект на все главы**  
   Каждая глава развивает тот же код, а не создаёт изолированные демо.

2. **Сначала архитектура, потом эффекты**  
   Слои, токены и контракты важнее «красивых трюков».

3. **Современный CSS без препроцессоров**  
   Без Sass, без Bootstrap, без лишней магии.

4. **Production-мышление**  
   Не только «как сделать», но и «как поддерживать».

5. **Практика важнее перечисления свойств**  
   Каждая возможность применяется в реальном контексте интерфейса.

## Как читать эту книгу

1. Изучите соответствующую тему в теоретической книге [Modern CSS 2026](https://github.com/rustkas/Modern-CSS-2026)
2. Выполните главу этого практического руководства
3. Сразу применяйте изменения в проекте Nova
4. Не перескакивайте через архитектурные главы
5. В конце у вас должен получиться цельный рабочий результат
